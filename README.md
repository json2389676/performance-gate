# Kit inicial

Resultados de tres pruebas de carga con JMeter sobre la misma aplicación. Cada prueba duró 5 minutos con 50 usuarios virtuales.

| Archivo | Qué contiene |
| --- | --- |
| resultados/produccion-actual.csv | Cómo funciona hoy la aplicación en producción |
| resultados/version-a.csv | Cómo funciona la versión nueva A |
| resultados/version-b.csv | Cómo funciona la versión nueva B |

Cada línea es una petición de un usuario virtual. La explicación de cada columna está en el documento del reto.
